# Alternate-source web search (excluding ModDB and Nexus)

Searched Oct 2026. "official" = author/project host; "mirror" = third-party archive (verify before use).

## Morrowind
- Province: Cyrodiil: no other source. Successor Project Cyrodiil is Nexus-only.
- Skyrim: Home of the Nords: Nexus only (needs Tamriel_Data).
- Arktwend: official German installer on sureai.net/games/arktwend; English patch via ModDB. Partial.
- Ashes of Apocalypse: GitHub Mindwerks/aoa release v1.1 (aoa1_1.zip 30 MB). USE. LoneBullet mirrors v1.1.
- Sea of Destiny: mirrors only (LoneBullet 82 MB exe, GameWatcher sea_of_destiny.exe).
- Morrowind Stargate: author site mod-stargate.rochmedia.com (forum link); mirror GameWatcher Stargate_1-1.7z, LoneBullet.
- Sotha Sil Expanded: mirrors have v2.0 only (LoneBullet, GameWatcher). Current 3.1 Nexus only.
- Chaos Heart Reshaped: fullrest.ru, tesall.club (login). Russian.
- Ultima IX Redemption: GitHub OpenMW/UIX-R Libre Edition 1.3 (assets pack, zip/tar). Original archive: ultima9.ultimacodex.com.
- Starwind: Nexus only. MET, Comes Alive, Landscape Retexture, skies .iv, BCOM: Nexus only (zettamods.com mirrors skies/landscape).

## KOTOR
- KotOR Ultimate: Deadly Stream file pages 998 (Endar Spire), 1017 (Taris Upper City). Deadly Stream limits anonymous speed; no direct URL verified.
- Yavin IV: Deadly Stream file 1593; GameFront mirror.
- Ryloth: never released. Darth Revan's Empire: not found.
- Sleheyron: Deadly Stream file 2754 (3.3, 3.15 GB).
