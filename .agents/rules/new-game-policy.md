# Policy: Adding New Games to PlayBound

**MANDATORY FOR ALL AI AGENTS:**
1. Before adding any game to PlayBound, you MUST read and follow `platform/docs/new-game-checklist.md`.
2. **Games must ONLY be entered via a browser and the PlayBound Admin Panel (`/admin/games`).**
3. Never insert bare unverified catalog rows into code files. Complete all 6 checklist steps (Install recipe, Full 8-item Editorial package, Multiplayer adapters, Controller support, Total conversion editions, and Mods) in the same session.
